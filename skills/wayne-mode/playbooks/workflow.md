# 工作流

工作流是用户编排：人在图上安排节点和连线。大模型只是其中一种节点，不是工作流本身。没有大模型节点的图同样走下面的分法。

| 在做的事 | 技能 |
| --- | --- |
| 建图、存图、草稿与发布、新增一种节点 | `standard-graph-workflow-editor` |
| 按图执行：节点输出写入共享状态，后续节点用模板引用前驱 | `standard-llm-workflow-runtime` |

画布和执行分开。改图的存储、校验、发布时只开编辑器技能。跑图、解析 `{{node_id.field}}`、做单步调试时才开执行技能。

路径事先定死、节点之间没有变量表达式的装配流程，不用执行技能里的模板解析。这种流程若只是后台任务，改看 [celery](celery.md)。
